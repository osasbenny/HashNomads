# HashNomads — Delivery Roadmap

## Phase 0 — Foundation (current)
- Brand/name established: HashNomads.
- Repository initialized.
- Product, design, architecture, data, integration, security, QA and operations specifications established.
- Profit model intentionally deferred to next dedicated workstream.

## Phase 1A — Engineering foundation
- Monorepo/toolchain.
- CI, lint, typecheck, tests.
- Environment validation.
- Database/migrations/seeds.
- Auth/RBAC/audit.
- Design tokens/component primitives.

## Phase 1B — Public product
- 2027-standard marketing site.
- ASIC catalogue/detail.
- Facilities sandbox.
- Scenario calculator interface.
- Transparency/risk/legal surfaces.

## Phase 1C — Commerce/onboarding
- Account/profile.
- KYC sandbox adapter.
- Orders/quotes.
- Payment sandbox + signed/idempotent webhook simulator.
- Terms/risk acceptance records.

## Phase 1D — Mining operations core
- ASIC registry.
- Ownership assignment.
- Facility/deployment state machines.
- Pool adapter + deterministic sandbox.
- Telemetry ingestion/freshness.
- Rewards ledger.
- Wallet destinations.

## Phase 1E — Customer + operations experience
- Customer dashboard/miner detail/earnings/billing.
- Admin operations console.
- Fleet health/incidents.
- Billing/reconciliation.
- Integration health/support/audit.

## Phase 1F — Hardening
- Full automated test suite.
- Responsive/accessibility pass.
- Security/threat-model pass.
- Performance/observability pass.
- V1 evidence report.

## Gate: Phase 2 Ready
All acceptance criteria in `07-TEST-ACCEPTANCE.md` must pass. No live hosting claims or production mining orders before this gate.

## Phase 2 — Physical infrastructure partnership
Detailed commercial plan is intentionally deferred until after the profit model workstream and V1 evidence. At minimum Phase 2 will cover reputable hosting/data-center partner diligence, energy/hosting economics, SLA, capacity, custody/ownership evidence, deployment/repair/retrieval procedures, insurance, integrations and legal/compliance activation.

## Later possibilities (not V1 commitments)
Multi-facility routing, customer fleet migration, advanced energy/curtailment analytics, hardware resale marketplace, enterprise API, mobile app, predictive maintenance, direct miner-management integrations, and HashNomads-owned infrastructure.
